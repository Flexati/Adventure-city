# Ash Docks — Terra, giro 3: rifacimento GPT

Questa cartella contiene i 15 PNG grezzi prodotti per la consegna «rifacimento a mano». Sono un set distinto da quello nella cartella superiore: gli originali precedenti non sono stati sostituiti.

Strumento usato per ciascuno dei 15 PNG: OpenAI Image Generation. I file sono riportati come usciti dal generatore, senza ritaglio né ridimensionamento. I tre file quadrati (`gpt_pad_nitro_porto.png`, `gpt_slick_olio_a.png`, `gpt_slick_olio_b.png`) sono 1254 × 1254 px; la specifica richiede 1024 × 1024 px. Misure, ritagli e controlli spettano al team. Il generatore non garantisce proporzioni, verde esatto o corrispondenza perfetta fra le varianti.

Le istruzioni operative sono in [PROMPT_CLAUDE_OPUS_5.md](PROMPT_CLAUDE_OPUS_5.md).
