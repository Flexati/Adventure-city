## Canon constraints

- Nox and Lulù remain the player-controlled protagonists of the first game.
- Kairn and Morrow remain mysterious, non-player supporting allies; their full origin belongs to Part II.
- Archon/Elena remains the final narrative victory of the current game.
- Chrono Shadows / Book of Broken Hours is a continuation hook, not a replacement for the ending.
- New bosses and enemy families should extend the V8 campaign rather than replace the existing core.
- These are visual-development boards. Any runtime sprite atlas still requires frame cleanup, pivots, transparency, collision/attack validation and mobile performance QA.
