# Adventure City — Chrono Shadows artboards

This folder contains the complete Chrono Shadows visual-development board set prepared for the Adventure City expansion.

## Important production rule

These are **art-direction / animation-planning boards**, not automatically production-ready sprite atlases. Before runtime integration, individual sprites and frames must be cleaned, normalized and validated for transparency, frame size, pivot, collision boxes, attack boxes, identity consistency and mobile performance.

The boards are stored here as **original-dimension high-quality WebP files** to preserve the complete visual reference while keeping repository weight reasonable.

## Narrative integration constraint

The current Adventure City protagonists remain the player-controlled leads. The martial-arts chrono fighter and the chainsaw/shotgun survivor are reserved mainly for the final part of the game as powerful AI-controlled/supporting allies. They must not steal the player's final victory.

Their sequel hook is that they were displaced into this world without knowing why and are searching for a temporal relic tentatively called the **Book of Broken Hours**, which may allow them to return to their own time.

The current game's main story must still end satisfactorily. The Book of Broken Hours is a continuation hook, not a substitute for the ending.
