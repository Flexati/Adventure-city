# Chronos Adventure: Nox & Lulú — Remix platformer

Reinterpretazione d'azione 2D ambientata a Vanta (Moon Refuge, Toxic Slum Bazaar, Clockwork Outpost) con boss Archon.

- Nox: colpi temporali a distanza. Lulú: scatto invulnerabile e doppio salto. Cambio eroe istantaneo.
- Potere Chronos: rallenta il mondo, gli eroi restano veloci.
- Game feel: coyote time, jump buffer, salto variabile, hitstop, screen shake, particelle, camera con anticipo.
- Controlli touch per Android WebView, pausa automatica in background, progressi salvati.

Sorgenti React/TanStack Start (canvas 2D, nessuna dipendenza extra). Branch separato: il gioco principale non è stato modificato.
